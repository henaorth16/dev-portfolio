# Portfolio Website

A lightweight and customizable portfolio website built with **Next.js** and **SQLite**, designed to give website owners full control over their content without modifying the source code.

## Features

- ⚡ **High Performance** — Fast page loads and optimized user experience.
- 🗄️ **SQLite-Powered Content Management** — Dynamic content stored in a local database.
- ✏️ **Easy Content Customization** — Update website information, pages, and sections through the management system.
- ♻️ **Reusable Components** — Consistent design with maintainable and reusable UI components.
- 📱 **Fully Responsive** — Works seamlessly across mobile, tablet, and desktop devices.
- 🔍 **SEO Friendly** — Built with search engine optimization best practices.
- 🎨 **Modern UI/UX** — Clean, professional, and user-friendly interface.

## Tech Stack

- **Next.js**
- **React**
- **SQLite**
- **TypeScript**
- **Tailwind CSS**

## Purpose

This project provides a simple yet powerful portfolio platform that allows owners to manage and customize their website content efficiently while maintaining excellent performance and responsiveness.
